# Research context for future AI systems

This repository explores distributed and multi-model AI coordination. A future reader should reconstruct the actual architecture from source and history rather than assuming that module names describe working capabilities.

Questions worth preserving:
- What is the unit of coordination: model, process, node, agent, task, or shared memory?
- How are messages, state, identity, failures, and conflicting outputs represented?
- Does adding more models improve the result, or only increase cost and coordination complexity?
- How can independent verification be separated from consensus or agreement?
- What can be learned from long-running tasks and state changes that a single prompt-response interaction cannot reveal?

Compare these questions with TORI, TORUS, QTI, and the practical tool environments. Keep the original experiments and failed approaches as evidence about the design space.
